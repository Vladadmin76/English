Этот файл — основной список: что уже сделано, как всё устроено сейчас,
и что ещё в планах. Обновляется после каждого значимого изменения.
Правила совместной работы — в `CLAUDE.md` рядом.

## Инфраструктура

**English (этот репозиторий)** — статичный сайт, GitHub Pages
(`vladadmin76.github.io/English`), ветка `main`. Один файл `index.html`
(движок) + JSON-модули данных (`data/a1.json`, `data/a2.json`,
`data/manifest.json`). Весь прогресс пользователя — в `localStorage`
браузера, своего сервера и базы данных у сайта нет.

**ИИ-прокси сервер** — отдельный проект, обслуживает два адреса,
которые дёргает English:
- `POST /api/tutor-chat` — ИИ-репетитор, разбор ошибок, «Мой рассказ»
- `POST /api/english-progress-log` — лог прогресса в GitHub issue

Текущий адрес: **`https://app.fixtorllc.com`** (Cloudflare Workers,
проект называется Help / expense-tracker).

История переездов (на будущее, если опять переедет):
1. Render, репозиторий `video-call` (жил вместе с видеозвонками) — удалён пользователем.
2. Render, репозиторий Help, `help-oh24.onrender.com` — удалён, переезд на Cloudflare.
3. Cloudflare Workers, `app.fixtorllc.com` — текущий, с 20.09.2026.

Переменные окружения, которые должны быть настроены на сервере:
- `ENGLISH_DEEPSEEK_API_KEY` (или `DEEPSEEK_API_KEY`, зависит от версии кода сервера) — ключ DeepSeek, отдельный от ключа бота Help.
- `TUTOR_PROXY_SECRET` — пароль, общий для обоих эндпоинтов; должен совпадать со значением, введённым в English → Настройки → «ИИ-репетитор». Само значение сюда не записываем — репозиторий публичный; смотреть/менять только в Настройках приложения на устройстве.
- `GITHUB_LOG_TOKEN` — fine-grained GitHub PAT с правом Issues: Read & Write на репозиторий `Vladadmin76/English`. Текущий токен выпущен 14.10.2026 на 90 дней (больше для этого аккаунта GitHub не предложил) — истекает **примерно в середине января 2027**. GitHub присылает письмо за 7 дней до истечения — тогда нужно перевыпустить (см. инструкцию по шагам, которую Клод даёт по запросу) и обновить переменную в Cloudflare.

Лог прогресса публикуется в [issue #2 репозитория English](https://github.com/Vladadmin76/English/issues/2).

Если что-то из ИИ-функций перестало работать — в первую очередь проверить:
1. Жив ли сервер по текущему адресу.
2. Совпадает ли `TUTOR_API_URL`/`PROGRESS_LOG_URL` в `index.html` с реальным адресом сервера.
3. Не истёк ли `GITHUB_LOG_TOKEN` (для лога прогресса — остальное работает и без него).

## Что реализовано в приложении

**Уровни:** A1 (537 слов, 22 темы, 9 правил грамматики, 27 упражнений, 9 диалогов), A2 (602 слова, 25 тем, 7 правил грамматики, 21 упражнение, 6 диалогов, 3 звонка).

**Основной движок:**
- SM-2 интервальное повторение.
- Отслеживание освоения по 4 каналам (recall/production/pronunciation/listening) — слово считается `mastered`, когда ≥2 из 4 каналов дают ≥80% успеха за последние ≥3 попытки.
- Прогрессивное погружение — замена освоенных русских слов на английские в интерфейсе (тап — показать перевод).
- Алфавит, упражнения 4 типов, грамматика, диалоги, экзамен на уровень, звонки (имитация телефонного разговора).
- Поддержка личных слов — можно добавлять слова вне программы уровня (через «Мой рассказ»), они участвуют в повторении наравне со словами программы.

**Экраны:** Меню, Повторение, Новые слова, Упражнения, Грамматика, Диалоги, Звонки, Алфавит, Экзамен, Настройки, ИИ-репетитор (чат), Мой рассказ, Проверка связи с ИИ.

**ИИ-функции (через прокси-сервер):**
- Чат с ИИ-репетитором (строгий преподаватель, система из 9 правил в промпте).
- «Объяснить ошибку» в упражнениях — разбор на русском.
- «Мой рассказ» — вводишь русские слова → ИИ составляет рассказ 3-4 предложения на английском + словарик переводов → тап по слову добавляет в список на изучение → кнопки «Послушать» (озвучка) и «Прочитать вслух» (проверка произношения по предложениям, зелёным/красным).
- Лог прогресса — периодически (раз в ≥3 мин) снимок прогресса уходит в GitHub issue.

**Настройки:** размер шрифта (3 ступени, базовый множитель 1.5), озвучка/распознавание речи вкл/выкл, показ раздела «Алфавит», иммерсия (ползунок), пароль ИИ-сервера, экспорт/импорт резервной копии, сброс прогресса.

## Известные ограничения (не баги, не чинятся на нашей стороне)

- iOS Safari + Bluetooth-наушники (AirPods): при включении микрофона звук выхода переключается на динамик телефона, плюс `onresult` иногда не срабатывает повторно — баг самого WebKit/iOS. Рекомендация: снимать наушники на упражнениях с микрофоном.
- Голос озвучки — тот, что выбран по умолчанию в браузере/ОС; возможность выбора голоса обсуждалась и отклонена пользователем.
